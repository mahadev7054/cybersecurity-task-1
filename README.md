# Secure Network Asset Inventory & System Information Scanner

## Cyber Security & Ethical Hacking Internship – Task 1

### Project Overview

This project is a Python-based system information and network asset inventory tool developed as part of Task 1 of the Cyber Security & Ethical Hacking Internship.

The application collects basic information about the local system and network and generates a system report.

## Features

- Hostname detection
- Local IP address detection
- MAC address retrieval
- Operating system information
- Network interface information
- System information report generation
- Saves collected information to a text file

## Technologies Used

- Python 3
- Linux / Kali Linux
- Git
- GitHub

## Project Files

| File | Description |
|------|-------------|
| `scanner.py` | Main Python system information scanner |
| `system_report.txt` | Generated system information report |
| `README.md` | Project documentation |
